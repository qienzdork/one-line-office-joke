# One-Line Office Joke

A single original one-line joke about office life: the raise that came back
as a pizza party. The program writes the joke to `OUTPUT_PATH`
(default `/output/entry.txt`) for the "One-Line Office Joke: 24-Hour Sprint"
competition on make.fun.
